Lesson Watcher

プライバシーポリシー

Lesson Watcher（以下「本ツール」）は、作成者本人のみが利用する個人用ツールです。本ツールが Google アカウントのデータをどのように扱うかを説明します。

アクセスする Google のデータ

  • 本ツールが組み込まれている Google スプレッドシート 1 つの内容（読み取りと書き込み）。ほかのファイルにはアクセスしません。
  • 本人宛ての通知メールの送信。受信したメールを読むことはありません。
  • 定期実行（トリガー）の設定。

データの使いみち

スプレッドシートのデータは、確認するレッスンの管理と、空き状況の記録・通知のためだけに使います。

データの保存場所

データは本人の Google アカウント内（スプレッドシートとスクリプトの設定）にのみ保存されます。本ツールの作成者が別途サーバーに保存することはありません。

第三者への提供

Google のデータを第三者に販売・提供することはありません。広告にも使いません。通知を送る場合も、送り先は本人のメールアドレス・Slack・LINE のみです。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、限定的な使用（Limited Use）の要件を含む Google API サービスのユーザーデータに関するポリシー に準拠します。

アクセスの取り消しとデータの削除

本ツールへのアクセス許可は Google アカウントの「サードパーティ製のアプリとサービス」 からいつでも取り消せます。スプレッドシートを削除すると、本ツールが保存したデータもすべて削除されます。
